Cara mengecek

1. Yang bisa langsung dicoba tanpa akun

  1. Halaman utama — cek daftar loker tampil, filter kategori/lokasi, dan pencarian.
  2. Share publik — buka /share/?job=<kode>; ini yang barusan diubah (gate token dihapus, jadi harus tampil tanpa akun dan tanpa token).
  3. Apply — form lamaran; cek validasi WA/email berjalan sebelum kirim.

2. Yang butuh login admin

  1. Masuk lewat /admin/ (login 3 tingkat: PIN master → admin → personal).
  2. Tab Config — ini yang baru selesai (#14): sebelumnya read-only, sekarang tombol simpan aktif dan memakai api.secure + toast.
  3. Tab Mail — review/approve/reject lamaran.
  4. Tab Jadwal — simpan/hapus jadwal + tugas. Reminder otomatis (cron 10 menit) baru aktif; perlu ada jadwal dulu agar benar-benar berbunyi.
  5. Tab DB Job / Pelamar — cek daftar & modal edit.

3. Yang tidak akan terlihat di preview ini

  1. Cron reminder agenda. Fungsi terjadwal tidak berjalan di server statis ini; ia hanya hidup di Netlify dengan config.schedule. Sudah diverifikasi lewat zisi, bukan lewat halaman.
  2. Perubahan backend lokal. Karena diproksi ke produksi, kode backend di tree ini belum ter-deploy — jadi behaviour-nya masih versi lama sampai Anda mengizinkan push.
